# Fibonacci Sequence Generator

A simple Python program that generates the **Fibonacci sequence** based on the number of terms entered by the user.

## How It Works

The program:

* Asks the user how many Fibonacci terms they want.
* Starts with `0` and `1`.
* Calculates each following term by adding the previous two terms.
* Handles invalid input such as zero or negative numbers.

## Example

```text
How many terms? 7

Fibonacci Sequence:
0
1
1
2
3
5
8
```

## Requirements

* Python 3.x

## Run the Program

```bash
python fibonacci.py
```
